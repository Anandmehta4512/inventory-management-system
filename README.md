# Inventory and Stock Management System

Full-stack inventory web application implementing core Data Structures:
- **Hash Table**: Instant O(1) product lookup & deletion.
- **Binary Search Tree (BST)**: O(log N) ordered storage with In-order traversal.

## Tech Stack
- **Backend:** FastAPI, Python, Pydantic
- **Frontend:** HTML5, Modern Tailwind CSS, Vanilla JavaScript
- **Storage:** JSON Database Persistence
