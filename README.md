# 📦 Enterprise Inventory & Stock Management System

A full-stack, enterprise-grade inventory management web application inspired by Zoho Inventory. Built with custom Data Structures & Algorithms (DSA) for high-performance stock tracking and order fulfillment.

---

## 🚀 Live Demo & Architecture
* **Frontend:** Deployed live on **Vercel** 
* **Backend API:** Deployed live on **Render** (`https://inventory-backend-api-s3tu.onrender.com`)

---

## 🧠 Core Data Structures Implemented
To ensure blazing-fast performance and ordered data processing, the backend implements custom core data structures from scratch:
* **Hash Table:** Provides instant **$O(1)$** time complexity for product lookup, retrieval, and deletion.
* **Binary Search Tree (BST):** Maintains sorted inventory records for efficient **$O(\log N)$** ordered storage and fast In-order traversals.

---

## 🛠️ Tech Stack
* **Backend:** FastAPI, Python, Pydantic, Uvicorn
* **Frontend:** HTML5, Modern Tailwind CSS, Vanilla JavaScript, FontAwesome
* **Storage:** JSON Database Persistence with live REST API integration
